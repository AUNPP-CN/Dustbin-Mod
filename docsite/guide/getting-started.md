# 快速开始

## 环境 要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 26.2 |
| 模组端 | Fabric Loader 0.19.5+ |
| Fabric API | 0.159.0+26.2 |
| Java | 25 |

Forge / NeoForge 尚未支持。

模组身份标识（mod id）是 `dustbin`，**不随模组端变化**；只有产物文件名带模组端后缀。把世界从 Fabric 构建切换到其他模组端时，存档里的垃圾桶与桶内物品可以原样保留。

## 安装

1. 前往 [GitHub Releases](https://github.com/AUNPP-CN/Dustbin-Mod/releases) 下载 `dustbin-fabric-<版本>.jar`
2. 放进 `.minecraft/mods/`（需要同时安装 Fabric API）
3. 启动游戏

## 它做了什么

原版里掉落物 5 分钟后直接消失；这个模组把它改成：**掉落物在设定时间后自动分类进桶**，你随时可以把东西捡回来。

- 物品存活时间达到阈值后，自动收入**对应的那个桶**，原版的 5 分钟消失逻辑被取消
- 对应的垃圾桶已满时（54 格全占、且没有同类物品所在格），物品**回落到原版行为**正常消失 —— 它是兜底，不是无限仓库
