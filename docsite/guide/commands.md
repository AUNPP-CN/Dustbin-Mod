# 配置与命令

## 收集延迟

| 操作 | 说明 |
| --- | --- |
| 默认值 | **1 分钟** |
| 可调范围 | **1 ~ 1440 分钟** |
| 作用域 | 全局（对四类桶统一生效，不按桶单独设置） |

通过 `/dustbin settime <分钟>` 调整，最小值 1 分钟。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/dustbin settime <分钟>` | 设置掉落物进桶的延迟（全局） |
| `/dustbin clear` | 逐桶报告当前存储并给出总计 |
| `/dustbin clear equipment` | 清空装备桶（别名 `tool`） |
| `/dustbin clear kitchen` | 清空厨余桶 |
| `/dustbin clear mineral` | 清空矿物桶 |
| `/dustbin clear other` | 清空其他桶（别名 `normal`） |

## 行为细节

- 桶满（54 格全占、且没有同类物品所在格）时，物品**回落到原版行为**正常消失，不会串到别的桶
- 开盖角度 95° 是设计取舍（略穿模），详情见 README
- 老存档平滑升级：1.0.0 世界直接可用，原普通桶里的物品一件不丢
